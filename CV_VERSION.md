# Athlo Dashboard - CV Version

## Project Overview

**Athlo Dashboard: Enterprise Sports Retail Management Platform**

Modern, production-ready dashboard for sports retail operations management.
Built with React 19, TypeScript, and Tailwind CSS, it consolidates e-commerce
orders, POS transactions, inventory management, and real-time analytics into a
single unified interface.

## Tech Stack

React 19 • TypeScript • Vite • Tailwind CSS 4 • React Query • React Router •
React Hook Form • Zod • TanStack Table • Recharts • Radix UI • Axios • React PDF

## Key Accomplishments

- **Engineered production-ready dashboard** using React 19 + TypeScript with
  full type safety (zero runtime errors)
- **Built enterprise-grade data tables** with TanStack Table: pagination,
  multi-column sorting, real-time search with debouncing, responsive design
- **Implemented secure JWT authentication** with automatic token refresh and
  protected routes
- **Developed complex multi-step forms** using React Hook Form + Zod: product
  wizards, variant management, bilingual support (EN/AR)
- **Created real-time analytics dashboard** with interactive Recharts (revenue
  trends, order distribution, KPI metrics)
- **Optimized performance** through code splitting, React Query caching,
  debouncing (60% API call reduction)
- **Built fully responsive design** supporting mobile, tablet, desktop with
  consistent UX
- **Implemented accessibility compliance** (WCAG AA): semantic HTML, ARIA
  labels, keyboard navigation

## Technical Achievements

- **8 Major Features**: Products, Orders, Analytics, Users, Coupons, Brands,
  Categories, In-Store Orders
- **25+ Reusable Components**: Consistent design system with dark/light mode
  support
- **100% TypeScript Coverage**: Zero `any` types, comprehensive type safety
- **Production Patterns**: Feature-based architecture, service layer, custom
  hooks, query key factory
- **PDF Invoice Generation**: React PDF with custom mapping for e-commerce and
  POS orders

## Performance & Optimizations

- **Code Splitting**: Each route lazy-loaded as separate chunk (faster initial
  load)
- **React Query Caching**: Intelligent cache management preventing redundant API
  calls
- **Debounced Search**: Reduced API load during user typing
- **Memoization**: Prevented unnecessary component re-renders
- **Suspense Boundaries**: Progressive component loading with skeleton states
- **Bundle Optimization**: Minified, tree-shaken, gzip compressed
